우주 타자 탐험 배포·사용 안내

버전 v1 · 5분 타자게임, 2자리 방 코드, 학생 닉네임, 개인별 찬스, 같은 방 랭킹, 스트레칭을 포함합니다.

배포 방식: 이 게임은 HTML 화면과 Netlify Functions·Blobs 서버를 함께 사용합니다. HTML 파일 하나만 열거나 public 폴더만 드래그해서 올리면 여러 기기 공유와 점수 계산이 작동하지 않습니다. 전체 프로젝트를 Git 저장소로 올리고 Netlify에서 가져오세요.

1. Netlify로 배포하기

  1. 압축을 풀고 우주타자게임_v1 폴더의 파일들을 새 GitHub 저장소에 올립니다. 저장소 맨 위에 package.json, netlify.toml, public, netlify, server가 있도록 합니다. node_modules는 올리지 않습니다.
  2. Netlify에서 새 프로젝트를 Git 저장소로 가져옵니다. Build command는 npm run build, Publish directory는 public, Functions directory는 netlify/functions입니다. 제공한 netlify.toml이 이 설정을 지정합니다.
  3. 환경변수 TEACHER_PASSWORD를 추가합니다. 학생이 모르는 8자 이상 교사용 비밀번호를 지정하고 Functions에서 사용할 수 있도록 설정합니다. 비밀번호를 HTML이나 Git 저장소에 적지 마세요.
  4. 환경변수 설정 후 새로 배포합니다. Node.js 22와 @netlify/blobs 의존성은 프로젝트 설정에 포함되어 있습니다. 배포된 Functions에서는 Blobs가 사이트 정보로 연결됩니다. 별도의 DB 비밀키를 학생에게 배포하지 않습니다.
  5. 배포 주소에서 선생님 방을 만들고, 다른 브라우저나 실제 학생 기기 2대로 학생 입장·함께 시작·게임 종료를 확인합니다. 실제 Netlify 계정에 배포하는 작업은 제공 파일에 포함되지 않습니다.

2. 수업에서 사용하기

  1. 선생님: ‘선생님 방 만들기’에서 사용하지 않는 두 자리 코드(00~99)와 교사용 비밀번호를 입력합니다.
  2. 한글게임 또는 영어게임, 단어 또는 문장, 찬스 0~10단계를 정한 후 ‘설정 적용’을 누릅니다. 학생 입장 후 ‘모두 함께 시작’을 누르면 5초 카운트다운 뒤 5분 동안 진행합니다.
  3. 학생: 같은 사이트의 ‘학생 입장’에서 방 코드·닉네임을 입력합니다. 진행 중에는 새 입장을 받지 않습니다. 다음 판 대기·결과 화면에서 참여할 수 있습니다. 한 방 최대 40명입니다.
  4. 운석의 글자를 직접 입력하고 Enter 또는 발사 버튼을 누릅니다. 운석을 클릭하면 목표를 선택할 수 있고, 다른 보이는 운석과 정확히 일치하는 글자를 입력해도 맞힙니다. 파이썬은 영문 입력 상태로 전환하고 대소문자·따옴표·기호·띄어쓰기를 그대로 입력합니다. 한글 조합 중 Enter는 발사하지 않습니다.
  5. 5분 후 같은 방의 이번 판 순위를 보여줍니다. 학생은 탈락하지 않아 끝까지 연습할 수 있습니다. 4판마다 결과를 15초 보여준 후 1분 스트레칭이 자동으로 시작됩니다. 선생님이 다음 판을 누르면 그 전에 쉬는 시간이 시작될 수도 있습니다. 휴식이 끝나도 게임은 자동 시작하지 않으며 선생님이 다음 판을 시작합니다.
  6. 선생님은 판이 끝난 뒤 ‘1분 스트레칭’을 직접 실행할 수도 있습니다. 우주고양이와 목 기울이기·어깨·손목·눈 쉬기를 15초씩 진행합니다. 불편한 동작은 하지 않아도 됩니다.
  7. 새로고침하면 같은 탭에서 이어집니다. 학생은 임의로 방 설정을 바꿀 수 없습니다. 명시적으로 나가거나 탭의 세션을 지우면 이전 닉네임을 다시 사용할 수 없으므로 새 닉네임이 필요할 수 있습니다. 선생님도 방을 만든 탭을 유지하세요.

3. 점수와 찬스 규칙

항목규칙
정답일반 운석 100점 + 글자 수 × 3점
오답점수 없음. 같은 운석은 다시 입력 가능. 운석당 오답은 한 번만 정답률에 반영
놓침지나간 일반 운석마다 −15점. 총점은 0점 미만으로 내려가지 않음. 게임 종료와 함께 남아 있는 운석은 감점하지 않음
찬스 추첨30초 간격으로 개인별 추첨, 단계 × 5% 확률. 0단계 0%, 10단계 50%. 많이 타이핑해야 생기는 방식이 아님. 낮은 순위에 별도 가중치를 주지는 않음

속도가 느린 학생에게도 찬스가 돌아가도록 했지만 무작위 추첨이므로 학생별 찬스 횟수는 다를 수 있습니다. 속도만 비교하기보다 ‘정확도 탐험가’와 ‘찬스 탐험가’도 함께 응원해 주세요.

4. 점수 조작 방지와 운영 범위

브라우저가 점수를 제출하는 방식이 아닙니다. 서버가 단어 일치·운석 출현과 제한 시간·같은 운석 중복·최소 입력 간격을 검증하고 기록에서 점수를 계산합니다. 붙여넣기는 화면에서 제한합니다. 다만 전문적인 자동 입력 프로그램이나 봇까지 완전히 차단하는 대회용 보안 체계는 아니며, 교실 체험용입니다.

방은 생성 후 6시간 동안 유효하며 선생님이 닫으면 코드 재사용이 가능합니다. 새 방은 새 데이터 공간을 사용합니다. 닉네임·이벤트 기록은 Netlify Blobs에 남으며 자동 삭제되지는 않습니다. 실명·개인정보 대신 별명을 사용하고, 필요할 때 사이트 관리자가 Blobs 저장소의 이전 기록을 정리하세요. 교사용 비밀번호는 이 사이트 전체에 공통 적용됩니다.

상태는 약 4초마다 동기화하며 실시간 순위는 판이 끝난 뒤 공개합니다. 네트워크가 끊긴 동안의 입력은 점수로 인정되지 않을 수 있습니다. 학생 기기 시간 대신 서버 시간을 사용합니다. Blobs 읽기·쓰기 및 Functions 호출이 발생하므로 Netlify 요금제와 사용량을 확인하세요. 실제 학급 전체 동시 접속 부하 검증은 배포 후 필요합니다.

5. 로컬 미리보기

Node.js 22 이상에서 프로젝트 폴더를 열고 npm install 후 npm run dev를 실행합니다. http://127.0.0.1:4173에서 확인할 수 있습니다. 기본 로컬 교사용 비밀번호는 teacher-demo-2026입니다. 로컬 저장소는 메모리이므로 서버를 다시 켜면 방과 점수가 사라집니다. 로컬 비밀번호는 Netlify 운영 배포에 자동 적용되지 않습니다. npm test로 서버·점수 규칙을 확인할 수 있습니다.

6. 문항 바꾸기

public/game-core.js의 BANK.ko.word, BANK.ko.sentence, BANK.en.word, BANK.en.sentence 배열을 수정한 뒤 다시 배포합니다. 문자열의 따옴표와 쉼표를 유지하세요. 이번 버전은 한 줄 코드 타자를 연습하며 Python 코드를 실행하지 않습니다.
